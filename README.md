# Collection-of-Practical-Tools
> Single-file Offline Toolkit | 单文件离线工具箱

## 📖 Introduction | 项目简介
A fully-featured offline toolkit with **171 built-in practical utilities**, packaged into a single HTML file. No installation or backend required. Most functions work without an internet connection. Simply download and open the file directly in your browser. All calculations run locally on your browser, your data will never be uploaded to any server to protect your privacy.

---

一款功能齐全的离线工具箱，内置**171个实用小工具**，打包在单个HTML文件内。无需安装、无需后端，绝大多数功能无需联网，下载后直接用浏览器打开即可使用。所有计算在本地浏览器完成，你的数据不会上传到任何服务器，保护隐私。

## ✨ Features | 功能特点
- 🧰 171 utilities divided into 11 categories: text processing, encoding conversion, math calculation, date & time, color utilities, developer helpers, hash & encryption, network tools, unit conversion, daily life tools, image & file tools.
- 🎨 7 built-in theme skins, one-click theme switching with quick light/dark mode toggle.
- 🔍 Real-time search to quickly locate target tools.
- 📋 One-click copy for tool output results.
- 📱 Clean responsive interface, works well on desktop and mobile browsers.
- 📦 Fully offline operation, no server-side dependency.

---

- 🧰 171款工具，分为11大类：文本处理、编码转换、数学计算、日期时间、颜色工具、开发辅助、哈希加密、网络工具、单位换算、生活工具、图片文件工具。
- 🎨 7套内置主题皮肤，支持一键切换，附带明暗模式快速开关。
- 🔍 实时搜索功能，快速定位需要的工具。
- 📋 工具输出结果支持一键复制。
- 📱 界面简洁自适应，电脑、手机浏览器均可正常使用。
- 📦 完全离线运行，无服务端依赖。

## 🚀 How to Use | 使用方法
1. Download the `toolkit.html` file from this repository
2. Double-click the file and open it with any modern browser
3. Find your target tool via the left sidebar or top search box and use it directly
4. All data processing is completed locally on your device

---

1. 下载仓库中的 `toolkit.html` 文件
2. 双击文件，使用任意现代浏览器打开
3. 在左侧分类栏或者顶部搜索框找到所需工具，直接使用
4. 所有数据处理均在本地完成

## 📌 Target Users | 适用人群
Developers, office workers, students and users who need various daily utilities.

---

开发者、办公人员、学生以及有日常工具需求的用户。
